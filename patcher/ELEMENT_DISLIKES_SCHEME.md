# Native vote display revision ? 0.3.11

The 0.3.10 device report fetched a dislike estimate but recorded zero bound slim actions, zero owned element text nodes, and no element counters. The user subsequently reported missing native likes. This establishes a display failure; it does not prove the like failure is caused by RYD. SponsorBlock is user-confirmed working and unchanged.

Read-only native analysis identifies a missing image path: ELMImageNode local images call YTELMResourceLoaderImpl imageWithName:color:bundleId: through the native client resource loader, bypassing the numeric icon resolver and compositor. 0.3.11 tags the returned image using native vote-asset names, including Delhi and legacy resource names. UIImage tags survive registry eviction; a bounded 64-image registry also supports shared CGImage identity. Concrete ELMImageNode setters are observed because ASNetworkImageNode overrides the superclass image path. Original callbacks and image results are preserved.

Discovery follows Yoga parents as well as Yoga children. Flattened render nodes may share a supernode that does not preserve the like/dislike branches. Insertion requires exactly one up and one down icon, a down-only branch, an action-bar/segmented component role, a visible native watch view outside the player overlay, and a watch player identical to the active player with the fetched video ID. Explicit element video IDs must match when present; components whose targets are entity references instead use the native watch-player identity. Existing native children, like text, icons, commands, backgrounds and hit targets are preserved. Only an owned ASTextNode is appended, with Yoga enabled, native font/color and an accessibility estimate. Owned nodes are removed when their feature, video or visible watch binding expires.

The watch is also bound on appearance and through existing responder ancestry, instead of relying exclusively on didActivateVideo. No global window traversal or loading of offscreen views is performed. Background image/layout callbacks coalesce whole-watch refreshes at no more than four per second. Per-tree scans are bounded to 128 nodes, watch scans to 2048 views, and ancestry to 12 nodes/64 responders. Native model text is bounded to 128 KiB and only role/video booleans are retained.

The rolling-number adapter now passes all native text, font, color and skipAnimation arguments unchanged. When animation suppression is enabled, it uses UIView performWithoutAnimation and a Core Animation transaction on the main thread. This protects native number initialization and rendering; suppression of custom asynchronous digit animations is best effort. No estimate replaces the native like count.

Schema 3 RYD diagnostics contain schema 2 element diagnostics: entry counters for image loaders, concrete setters, layouts, scans and native number updates; watch binding/loading, watch-player equality, count/playback equality, tagged image count and the last gate. Background entries are counted under a lock. No asset names, model text, video IDs, account data or native text are logged. This corrects the earlier report, whose counters only incremented after several discovery gates.

[Device failure](profiles/device-0.3.10-vote-display-failure.json) and [native source/metadata evidence](profiles/element-dislikes-evidence.json) record the basis for this candidate. Compilation and normal production packaging are performed. Tests, static hook checks, GUI smoke checks and development service votes remain disabled. The revised count display is device-unverified; native automatic RYD votes and online Shorts remain unported. The merged settings UI and working authentication source are preserved.
